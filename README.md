# Forecast Error Report (Power BI)
I created this BI report for our demand planning and executive team to evaluate forecast errors by lag and analyze how inventory levels affect those error rates.

I just recreated this report with dummy data in an Azure SQL database so the report is using a database connection instead of excel files like some of my other example projects.

You should be able to download the .pbix in order to view and interact with the report, but you won't be able to refresh the data due to IP/Credential restrictions.

Notes:
- All data in this file is dummy data and I'll periodically add new data to the data tables so I can test my historical inventory and forecast scripts, so this report might have new data in the future!
